# Design system
Dark only. Tokens in `apps/web/src/index.css`.

| Token | Value | Use |
|---|---|---|
| bg | #070708 | page |
| surface | #0e0e10 | cards |
| line | #26262b | borders |
| fg | #f4f4f5 | text |
| muted | #a1a1aa | secondary text |
| subtle | #8b8b94 | tertiary |
| gold | #dcb464 | primary action / highlight |
| gold-hi | #ecc97f | hover |
| on-gold | #0a0a0b | text on gold |
| danger | #f1948a | form errors only |

Font: Inter. Gold is used sparingly. Motion is transform/opacity only and respects `prefers-reduced-motion`.
